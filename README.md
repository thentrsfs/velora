# Velora

A premium café website built with Next.js, TypeScript, Tailwind CSS, and GSAP.

## Features

- Responsive design
- GSAP page animations
- Interactive menu page
- Contact form with validation
- Mobile navigation
- Splash screen experience

## Tech Stack

- Next.js
- TypeScript
- Tailwind CSS
- GSAP
- React Hook Form
- Zod
